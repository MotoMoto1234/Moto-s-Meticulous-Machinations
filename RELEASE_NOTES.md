# Moto’s Meticulous Machinations v0.1.29

The first public release of Moto’s Meticulous Machinations brings **100 item, spell, feat, class feature, and monster feature entries** to the CPR Medkit, along with **three companion actors**.

- **Spells and items** include template-based Moonbeam and Conjure Elemental, a configurable Witch Bolt tether, Wall of Force placement, and consumable and ammunition automations.
- **Class features and feats** include configurable Hex Slinger, Eldritch Smite, Pact of the Blade, Guardian Coil, Lucky, and Protected.
- **Persistent companions** include the Drake Companion, Steel Defender, and Otherworldly Steed. Bind a world actor and use its linked tokens across scenes.
- **Player and GM prompts** support reaction requests, choices, and GM fallback after a timeout for supported workflows.
- **Optional Bleeding Out** adds turn-start death save prompts and configurable status art. Enable it in module settings if you want to use those rules.

This release targets **Foundry VTT v13** and **D&D 5e 5.2.5**. Enable CPR, Midi-QOL, Dynamic Active Effects, Times Up, SocketLib, and libWrapper. Sequencer and compatible JB2A assets provide optional visuals for supported automations.

Enable the Machinations compendiums in CPR’s **Additional Compendiums**, then apply the desired automation from the item’s **Medkit**. The [README](https://github.com/MotoMoto1234/Motos-Meticulous-Machinations/blob/main/README.md) covers installation and the [FAQ](https://github.com/MotoMoto1234/Motos-Meticulous-Machinations/blob/main/FAQ.md) covers recommended settings and companion setup.
